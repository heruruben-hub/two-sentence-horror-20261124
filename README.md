## What it does

`main.ts` writes one original horror story of exactly two sentences (190
characters) to `/output/entry.txt`. The second sentence quietly turns the
first: a daughter's nightly ritual for her dead grandmother hides the fact
that the narrator is the one no longer meant to be at the table. The program
validates the story against the competition gate before writing (1–400
characters, not only whitespace, exactly two sentences), then reads the file
back and checks it holds exactly what was written.

## Run it

```bash
node main.ts
```
